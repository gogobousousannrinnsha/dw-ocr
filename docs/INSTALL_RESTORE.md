# 復元・実行手順

[READMEの導入手順](../README.md)に従い、結合ツールと8個のtransport ZIPを同じ空フォルダーへ保存します。結合ツールだけ展開し、`join_parts.bat`を実行します。結合後のハッシュは`SHA256SUMS_RESTORED.txt`、取得ファイルは`SHA256SUMS_ASSETS.txt`で照合できます。SHA-256は内容一致の検査であり署名ではありません。

既存の異なる出力ZIPは上書きされません。同じハッシュの完成ZIPがある場合は既存ファイルを検証して成功終了します。欠落・破損・別版混在時は原因を表示し、新しい完成ZIPを公開しません。

復元ZIPを短く書込み可能な新規フォルダーへ展開します。取得部品・復元ZIP・展開先を合わせて15～20GB以上とOCR成果物分の空き容量を確保してください。展開後は同梱の`verify_environment.bat`で依存関係とGPUを確認します。

INPUTへXDWのコピーを入れて`OCR開始.bat`を実行するか、XDW・フォルダーをBATへドロップします。設定はsettings.iniです。終了時のOCR・矩形・確認画像の成功／失敗／未処理件数と保存先を確認します。失敗文書の内容はjob.jsonに記録されます。文書固有エラーは後続へ進み、GPU・モデル・保存領域などの共通エラーは停止します。

生成XDWをViewerで開き、修復警告、位置、可読性、選択・編集、別名保存・再表示を確認してください。OUTPUTの確認画像も文字と位置を確認します。runは原本コピーと認識文字を含むため、フォルダー一式を公開しないでください。

停止後はINPUT・OUTPUT・runs・runtime・models等を含むアプリ全体を移動できます。日本語Windowsで表現できない文字や長すぎるパスは避けてください。保護ソフトの設定を無条件で無効化する手順にはしていません。
