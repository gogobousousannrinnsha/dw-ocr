# 既知の制約

## Portable環境と補助ツール

- Windows x64・指定GPU構成が対象です。CPU自動切替や他OSでのDocuWorks動作は提供・保証されません。
- 全ページ処理は配布ZIPの補助ツールの仕様です。基盤Integrations 0.3.0の`ocr-xdw` CLI自体は指定1ページの処理です。
- OCRは誤認識・認識漏れ・領域の位置ずれを起こし得ます。文書の向き分類・傾き補正・文書unwarpは基盤の提供対象外です。
- 矩形追加とMarker付与は別機能です。Markerは外接矩形を基にした水平線で、斜め文字に沿った四角形ではありません。
- Viewerでの表示成功だけでは、修復警告がないことや編集できることを保証しません。
- 初回利用・更新時は原本をバックアップしてコピーを使ってください。補助コードはコピー出力と既存ファイル検査を実装していますが、同時実行や処理途中の障害まで原子的に保証するものではありません。
- テキストマップの引数と出力先は[実行手順](INSTALL_RESTORE.md)を参照してください。`--report`で既存manifest等を指定すると上書きし得るため、既定のレポート先を使ってください。

## 基盤ライブラリの既知事項

- Coreは明示的な`save()`が必要です。属性設定途中の失敗はハンドル内に部分変更を残し得るため、失敗後は保存せず閉じ、新しいコピーでやり直します。
- 別wrapperのキャッシュは削除操作と同期しません。削除後は古い参照を使わず再列挙します。0-byte User属性取得にも制約があります。
- Core 1.0.0ではPython 3.10で本体例外とclose失敗が重なると、`exc.add_note()`によって元例外が`AttributeError`で隠れる既知不具合があります。指定Portable Python 3.13の記録と区別してください。
- 基盤OCRでは0領域・失敗時に診断情報が残り、完成manifest・注釈を作らない仕様です。全ページ補助ツールは認識0領域のページをスキップします。その他のOCR例外では出力前に停止し、注釈・保存例外では作成出力の削除を試みます。

## 結果・プライバシー

OCR bundleや診断ログには、元文書コピー、画像、認識文字列、ファイルパス、実行環境が含まれる場合があります。JSONLやテキストマップも文書内容です。フォルダー全体をそのままIssueやReleaseへ添付しないでください。

SHA-256は内容一致の検査であり、電子署名、マルウェア検査、権利確認の代替にはなりません。モデル・ライブラリ配信元の将来の可用性も保証しません。

公開梱包版はcuDNN開発用includeとOpenCV FFmpeg動画プラグインを除外しています。画像OCR向けの実行環境であり、動画入出力やcuDNN開発環境としては使用しないでください。
