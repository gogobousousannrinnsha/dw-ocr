# 既知の制約

- Windows x64、正規DocuWorksと対応x64 XDWAPI、CUDA対応NVIDIA GPUが必要です。Python 3.13.15と同梱依存・モデルの組合せが今回の基準です。他PCや任意のGPUでの成功を保証しません。
- CPU自動切替、並列処理、自動再開、向き分類・傾き補正・文書のゆがみ補正は標準ワークフローにありません。
- OCR誤認識や位置ずれがあります。矩形付きXDWの生成は、検索用OCRテキスト層の埋込みではありません。確認画像は組版再現や校正結果ではありません。
- 選択領域のMarkerには13pt線幅の編集問題が残っています。今回の標準矩形処理とは別機能で、修正は含みません。
- SDK画像パスは255 UTF-16単位以内が必要です。Paddleが使うWindowsコードページで表現できない文字を含む配置では英数字の短いパスを使います。
- 日本語フォントが見つからなければ確認画像生成は失敗します。必要に応じsettings.iniで利用可能なフォントを指定してください。
- 新規出力名が必要です。保存runを直接編集せず、旧ページ別runは独立して利用します。失敗時診断はerror.jsonの相対参照から確認します。
- 動画入出力とcuDNN開発用includeは配布対象外です。Norton等の保護を回避する保証はありません。
- Viewerの確認は検証対象ファイルと環境に限ります。今回の確認区分は[検証記録](VERIFICATION.md)を参照してください。
