# v0.2.0からv0.3.0への移行

旧版と入力・runを残し、新版を新規フォルダーへ展開してください。既存フォルダーへの上書き更新は行いません。
Core 1.0.0、Python・GPU・モデル構成を維持し、Integrationsを0.6.0から0.7.0へ更新します。
settings.iniは新版を基準に必要な値だけ移します。通常のOCR操作・矩形・確認画像・既存JSONLは従来どおりです。

訂正・XDWレビューはPython APIとして追加しています。新しいGUI・CLI・BATは追加していません。
元runを明示し、訂正JSON、確認XDW、訂正後JSONLは元bundle外の新しい保存先へ出力します。
元OCR Result 1.0/1.1・既存ローダー対応の旧runを維持します。修正ファイルの自動検出・合成・再OCR結果への引継ぎはありません。
review.jsonと編集済みXDWを組にして保管してください。review形式1.0と2.0はそれぞれ対応するAPIを使用します。

停止後はアプリ全体を別の書込み可能なフォルダーへ移動できます。元runもフォルダー単位で保持してください。
問題があれば新版を停止して残してあるv0.2.0を使用します。0.7.0の訂正・レビューAPIは旧版にはありません。
