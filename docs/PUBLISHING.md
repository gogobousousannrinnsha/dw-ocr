# 保守・公開方針

公開リポジトリは独立した公開用コミット履歴を使用します。開発用`.git`、生ログ、実文書、OCR本文、個人パス、認証情報を移植しません。第三者の正当な権利表示は保持します。

v0.1.0は2026-09-09版を基にした公開梱包版2026-09-10です。再梱包したので旧版とはハッシュが異なります。Asset・結合ツール・manifest・READMEの期待値は同じ版で揃えます。

更新時はZIP内部とネストしたアーカイブを確認し、個別SHA-256・復元ハッシュ・CRCを再検証します。ソースやバイナリを変更した場合は、その変更に応じた実行検証を行い、結果と限界をRelease Notesへ記載します。

独自部分はMIT、第三者資産はそれぞれの条件です。依存更新時には付属LICENSE・NOTICE・対応ソースの必要性を再確認します。

公開前に対象を`gogobousousannrinnsha/dw-ocr`へ固定し、Git作者・コミッターと操作アカウントを確認します。ReleaseはDraftで全Assetのサイズ・ハッシュ・説明を照合後、Pre-releaseとして公開します。
